BUG FOUND AND FIXED IN SCOPE (cmd_sell bulk — latent since v22 A5)
-------------------------------------------------------------------
The bulk price map was keyed `prices[item.pk]` AFTER do_sell — but
do_sell deletes the row and Django nulls the in-memory pk, so every
sale wrote prices[None] and every read returned the LAST-sold price.
Numerically invisible pre-#138 (the skipped-counter kept batches
uniform-value; totals came out len(group) × last-price = correct for
uniform groups) but wrong for mixed-value groups and catastrophic with
0-value items in the batch (the whole batch partitioned worthless —
caught by this brief's own test 7). Fixed by keying on id(item). In
scope: cmd_sell's bulk path is this brief's §3.3. No thin issue filed
— the defective code no longer exists.
